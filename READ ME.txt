  The line of code you've provided:

const folder = req.baseUrl.split("/").pop();


is used in a Node.js application, specifically with Express.js, where req.baseUrl is the base URL for the request. This code essentially extracts the last part of the URL path.


Breakdown:

req.baseUrl: This is the base URL of the request, usually in a middleware that is mounted at a certain path in Express. For example, if the request URL is /api/users/123, and the route is defined as /api/users, then req.baseUrl would be /api/users.

.split("/"): This splits the baseUrl string into an array using the / character as a separator. For example, if req.baseUrl = "/api/users/123", after split("/") it would result in an array like: ["", "api", "users", "123"].

.pop(): This method retrieves the last element from the array (in this case, "123"). If the path was /api/users, it would return "users", and if the path was /api/items/42, it would return "42".



Example:

If req.baseUrl = "/api/products/456", the result would be:

const folder = req.baseUrl.split("/").pop();
// folder will be "456"


So, this approach is useful when you want to extract the last part of the URL path

// middleware/authorizeRole.js

const authorizeRole = (...allowedRoles) => {
  return (req, res, next) => {
    if (!req.user) return res.status(401).json({ message: "Unauthorized" });

    if (!allowedRoles.includes(req.user.role)) {
      return res.status(403).json({ message: "Access denied: Insufficient permissions" });
    }

    next();
  };
};

module.exports = authorizeRole;


✅ This allows you to restrict any route like:

router.get("/", protect, authorizeRole("dietitian", "advisor"), handler);
